# 鹤游江山

一个在浏览器里玩的 3D 小游戏，画风取自北宋王希孟《千里江山图》的青绿山水。

**在线玩：** https://mhy-geek.github.io/heyou-jiangshan/

## 玩法

开场是一卷完整的青绿山水，点“入画”后颜色褪成水墨。你操控一只白鹤沿河西行，飞过之处山水重新着上石青石绿。画里有十处景致，各有一个朱砂红点标记，飞近就算寻得；十景集齐，整卷恢复青绿。

想细看某一处，可以随时落下来，站在景前慢慢环顾。

## 操作

| 按键 | 作用 |
| --- | --- |
| W / S | 升 / 降 |
| A / D | 左转 / 右转 |
| 空格 | 振翅加速；落地时起飞 |
| F | 降落 / 起飞 |
| M | 静音 |

落地后：A / D 或拖动鼠标环顾，W / S 俯仰，滚轮拉远拉近。

## 本地运行

整个游戏只有一个 `index.html`，双击用浏览器打开即可（需要联网，从 CDN 加载 three.js 和字体）。

## 技术

- three.js r128，全部山形、树木、亭桥、舟船都由代码生成，没有外部模型或贴图
- 自写着色器：青绿设色、披麻皴笔触、墨线勾边、旧绢纹理
- 声音由 Web Audio 实时合成
